Add Auto-Replies during a stream

Auto-Replies · v0.4.53.beta2+

Moderators and the broadcaster can use !addcommand commandname commandresponse. Enable Auto-Replies and connect authorised native Twitch chat and a separate bot account first.

Example: !addcommand socials Follow me at example.com. Viewers can then type !socials. New replies allow everyone with a 30-second cooldown.

The bot confirms after saving. Existing names are not overwritten; edit replies in OMSC. Use the channel's configured prefix for both commands.
