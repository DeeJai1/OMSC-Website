EARLY ACCESS

Request OMSC beta access

Help test new features before they reach the public stable release.

How to request participation

Open OMSC, go to Help → Beta Access and select Request Beta Participation. Complete the request using your connected Twitch identity and your Discord username. Requests are reviewed; submitting one does not automatically grant access.

The website application form is not yet connected. For now, please submit through the application so your request uses the existing beta-management process.

What to expect

Beta builds may contain bugs or unfinished features. Keep backups of your settings and report problems through the OMSC Discord community. Beta approval is tied to your verified Twitch account and may expire or be revoked.

How beta updates work

Approved testers can be offered a separate beta update when an eligible newer build is available. Regular public updates remain available. Beta downloads are authorised and verified before installation; no private GitHub access is required.

Beta builds are not the same as public stable releases, and the updater does not offer automatic downgrades.
